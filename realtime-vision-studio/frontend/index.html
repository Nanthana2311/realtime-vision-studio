🏗️ Real-Time Full-Stack Machine Learning Architecture

In classical web development, browsers communicate with servers via simple request/response HTTP. However, real-time Computer Vision requires continuous streaming with sub-50ms round-trip latency. Here is how this application achieves that:

1. The Data Pipeline

[ Browser Video Element ]
          │  Grabs frame at 15–30 FPS
          ▼
[ Offscreen HTML5 Canvas ]
          │  Resizes to 320x180 & compresses to JPEG (Quality 0.65)
          ▼
[ Bi-directional WebSocket ] (ws://host/ws/vision)
          │  Sends base64 frame payload + client timestamp
          ▼
[ FastAPI Async Server ]
          │  Receives payload; schedules inference in thread pool
          ▼
[ VisionEngine (OpenCV / YOLO) ]
          │  Detects bounding boxes & updates Centroid Tracker
          ▼
[ Lightweight JSON Broadcast ]
          │  Returns coordinates [[x,y,w,h], label, conf, crossings]
          ▼
[ Front-End Canvas Overlay ]
             Draws high-speed vector overlays on top of raw video!

2. Why This Pattern Outperforms Naive Streaming

  • Zero Video Re-Encoding: Naive systems re-encode bounding boxes into video frames on the server and stream heavy MJPEG back. This wastes bandwidth and CPU. In VisionStudio, the server only returns a tiny JSON array of coordinates (less than 200 bytes per frame)!
  • Non-Blocking FastAPI Worker Pool: ML models are CPU-bound. If called synchronously inside an async def route, Python's GIL would freeze every other WebSocket. By using asyncio.to_thread, FastAPI keeps the event loop free to handle hundreds of concurrent streams.
  • Persistent WebSocket Connection: Avoids the TLS handshake and HTTP header overhead on every single frame.

💻 How to Plug In Your Own Model (YOLOv8 / PyTorch / ONNX)

You can replace the default OpenCV cascades with your own trained weights in backend/vision_engine.py in less than 15 lines of code:

Plugging in Ultralytics YOLOv8:

from ultralytics import YOLO

class VisionEngine:
    def __init__(self):
        # 1. Load your trained weights once on startup
        self.model = YOLO("yolov8n.pt") # or your custom weights "best.pt"
        self.tracker = CentroidTracker()

    def process_frame(self, frame, confidence_thresh=0.5):
        # 2. Run inference
        results = self.model.predict(frame, conf=confidence_thresh, verbose=False)
        detections = []
        
        for r in results:
            for box in r.boxes:
                x1, y1, x2, y2 = box.xyxy[0].tolist()
                cls_id = int(box.cls[0].item())
                label = self.model.names[cls_id]
                conf = float(box.conf[0].item())

                detections.append({
                    "label": label,
                    "confidence": round(conf, 2),
                    "bbox": [int(x1), int(y1), int(x2 - x1), int(y2 - y1)],
                    "color": "#10B981"
                })
        return detections
